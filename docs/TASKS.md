# Tasks

One row per task, generated from the catalog (`uv run mengine-bench tasks-doc
--write`); a test fails when this table drifts from the code. Every task counts
the same in Correct % (docs/SCORING.md): there are no weights, suites or par
times.

## Multi-step tasks

`cmp-*` tasks have two steps. The second runs with `fresh_session` (a new agent
process, no chat history) and `carry` naming the summary file: the runner
builds a new workspace that contains only that file (plus AGENTS.md), under
a separate system-temp root, so neither the source nor any copy of it, nor
the step-1 workspace, is inside or above the step-2 directory. `hide` also
names the source for the record. No step resumes a session, so every harness,
`cmd` included, runs every task. What remains unenforced: an agent that
ignores AGENTS.md could still open an absolute path elsewhere on the disk;
only an OS sandbox around the agent closes that.

## Deliverables

A task may declare `deliverables`: workspace files the bundle keeps verbatim
(after redaction) under `judge/<task>/<file>` for the maintainer's judge. The
visual tasks declare their page, which the judge renders headless.
